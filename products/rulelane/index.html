Install in Cursor

  1. Purchase via the Buy button (or email us). After payment, download the zip from the confirmation email or delivery page.
  2. Unzip the download. Open the pack folder you need.
  3. Copy .cursorrules and AGENTS.md into your project root (next to package.json, pyproject.toml, or go.mod).
  4. Open the project in Cursor. Start an Agent/Chat session—the rules load with the workspace.
  5. Optional: merge into existing rules or split into .cursor/rules/ with path globs. Details are in each pack’s README.

VS Code / Copilot: keep AGENTS.md at the root, or mirror bullets into .github/copilot-instructions.md.
